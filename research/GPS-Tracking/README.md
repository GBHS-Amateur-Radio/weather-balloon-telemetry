# GPS Tracking

GPS system documentation for our high altitude weather balloon.

## Document Overview

  - Document: GPS-module-guide.pdf
  - Site: https://ukhas.org.uk/doku.php?id=guides:gps_modules
  - Content: Discusses GPS modules that can work with our weather balloon. In specific, it outlines modules that can continue transmitting data at altitudes above 18km (50,000 ft) and speeds of 1000 knots. These rule are known as the COCOM limit.
