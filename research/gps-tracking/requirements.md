# GPS & Tracking Requirements

## Purpose

The GPS subsystem will determine the position and altitude of the payload during the flight and provide that position data to the telemetry and recovery systems.

<br>

| Requirement | Target | Reason | Source |
|---|---|---|---|
| Maximum operating altitude | TBD | GPS must operate above the maximum expected balloon altitude | Flight profile / mission requirements |
| Position accuracy | TBD | Position must be accurate enough for tracking and payload recovery | TBD |
| Update rate | TBD | Position must be updated frequently enough for telemetry and tracking | Telemetry requirements |
| Operating temperature | TBD | GPS hardware must tolerate the expected payload environment | Environmental requirements |
| Supply voltage | TBD | GPS must be compatible with the payload power system | Power system requirements |
| Communication interface | TBD | GPS must communicate with the flight computer | Flight computer requirements |
| Mass | TBD | GPS system must remain within the payload mass budget | Payload mass budget |
