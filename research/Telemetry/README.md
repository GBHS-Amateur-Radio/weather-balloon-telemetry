# Telemetry Overview

Documentation for the telemetry system we'll use on the weather balloon.

## Telemetry Requirments
  -  Long-Range Communication over 40km (about 130,000 ft)
  -  High reliability and error correction
  -  Reliable coverage over the expected flight area
